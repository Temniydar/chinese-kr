# 🇨🇳 Тренажёр для подготовки к Контрольной Работе по Китайскому Языку

Интерактивное веб-приложение, разработанное специально по материалам вашей контрольной работы (12 билетов + теоретический блок кафедры).

## 🚀 Как запустить

- **Вариант 1 (быстрый)**: Дважды кликните по файлу `Запустить_Тренажер.bat` — он сам поднимет сервер и откроет страницу в браузере.
- **Вариант 2**: Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Яндекс, Firefox).
- **Вариант 3 (онлайн-сервер)**: Приложение уже работает по адресу [http://localhost:8088](http://localhost:8088).

---

## 🌟 Возможности тренажёра

### 1. 📖 Все 12 экзаменационных билетов
Каждый билет разобран до мельчайших деталей:
- **Задание 1 (12 баллов)**: 12 слогов с правильными тонами, разбором инициалей, финалей и живой китайской озвучкой при клике. Доступна кнопка **«Озвучить все слоги по очереди»**.
- **Задание 2 (6 баллов)**: Чтение пиньиня с правилами модуляции тонов:
  - Правило `3+3 = 2+3` (например, *nǐ hǎo ➔ ní hǎo*, *měi hǎo ➔ méi hǎo*, *guǎn lǐ ➔ guán lǐ*);
  - Полутретий тон `3 + 1, 2, 4` (*lǎoshī*, *běnlái*, *hěn bàng*, *zhǔn bèi*);
  - Нулевой/нейтральный тон (*mèimei*, *dìdi*, *tóufa*, *hǎo ba*).
- **Задание 3 (6 баллов)**: Устный перевод предложений с русского на китайский с режимом самопроверки («Показать ответ»), иероглифами, пиньинем, разбором грамматики и озвучкой.

### 2. 🎯 Интерактивная проверка (Урок ➔ Проверка ➔ Ошибки)
- **🎵 Аудио-диктант**: программа произносит слог — вы выбираете правильный слог и тон среди вариантов.
- **🔄 Блиц-тест правил тонов**: проверяет понимание, как трансформируется тон в парах и тройках слогов.
- **🧩 Конструктор предложений**: интерактивный сборщик китайских предложений из блоков слов для закрепления грамматики (порядок слов, позиция *dōu*, *yě*, связка *shì*, частица *de*).

### 3. ⏱️ Симулятор Контрольной Работы
- Выбор любого билета или случайный билет по кнопке **«🎲 Случайный билет»**.
- Таймер на 5 минут подготовки.
- Интерактивная самооценка ответа с расчетом баллов (из 24) и итоговой оценкой (5 / 4 / 3 / 2).

### 4. ❌ Работа над ошибками
- Все сложные слоги, неправильно решенные вопросы в тестах и отмеченные фразы автоматически сохраняются в персональный банк ошибок.
- Можно гонять тренировку **только по проблемным местам**, пока результат не станет 100%!

### 5. 💡 Шпаргалка и Теория (Страница 7)
- Полная структурированная теория по фонетике (модуляция тонов, нулевой тон, звуки `ü`, `-ian`, `-iang`) и грамматике (*shì*, *yě*, *dōu*, притяжательная *de*) с кликабельной озвучкой всех примеров.

### 6. ⚡ Разминка скорости чтения
- Генератор порций по 10 слогов из общей базы для разминки артикуляции перед тестом с озвучкой каждого слога.
